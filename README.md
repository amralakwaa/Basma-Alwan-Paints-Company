# دهانات الرياض | Riyadh Painting & Decor

**الموقع الرسمي لـ [دهانات الرياض](https://dahanyatriyadh.com/)، معلم دهانات وديكورات في الرياض.** يقدّم دهانات داخلية وخارجية، وبروفايل، وديكورات فوم وبديل الخشب والرخام، وأرضيات إيبوكسي، وعزل أسطح، وتركيب ورق جدران وجبس بورد، وترميم مبانٍ.

الموقع مبني بـ PHP، وفيه واجهة عربية من اليمين لليسار، ولوحة تحكم يدير منها صاحب النشاط الخدمات والمشاريع والمقالات والمدن والتقييمات والطلبات.

🌐 **الموقع:** [dahanyatriyadh.com](https://dahanyatriyadh.com/)

## ماذا يحتوي المشروع؟ | What's inside

<div dir="rtl">

### للزائر (الواجهة العامة)
- **صفحات خدمات** لأكثر من 20 خدمة دهان وديكور وترميم.
- صفحة أسعار، و**حاسبة تكلفة**، ومعرض صور قبل وبعد، وصفحة مقارنة، ودليل للعميل.
- مشاريع منفّذة، ومدونة، وأسئلة شائعة، وعروض، وصفحات للمدن.
- **تقييمات العملاء:** صفحة لعرضها وصفحة يضيف منها العميل تقييمه.
- نموذج طلب يصل مباشرة إلى لوحة التحكم.

### لصاحب النشاط (لوحة التحكم)
- إدارة الخدمات، والمشاريع، والمقالات، والمدن، والتقييمات، والأسئلة الشائعة، والطلبات، والإعدادات.

### السيو المحلي
- عنوان ووصف لكل صفحة، وخريطة موقع XML، وملف `robots.txt`.
- بيانات منظمة (JSON-LD): الخدمات وكتالوج العروض، والتقييم الإجمالي، والأسئلة الشائعة، والموقع الجغرافي وساعات العمل، والبحث داخل الموقع.

</div>
